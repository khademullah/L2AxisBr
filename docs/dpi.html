tb_l2br.sv · DPI-C

The bench calls C. The bridge does not.

Every DPI-C call is in hdl/tb_l2br.sv. pkt_l2br never calls C. The imports are at the top of the testbench. File format and BPF come from dpi/pcap_reader.c. The MAC-table twin is dpi/l2_model.c.

Pcap reader

These run once before the replay, then once per frame. A beat on the AXI-Stream is still tvalid && tready in SystemVerilog. C only hands the bench the stored bytes.

FunctionReturnsLineRole
open_pcap(filename)int662Opens the file named by +PCAP=. A nonzero return ends the sim.
get_datalink()int666Requires DLT 1. Anything else closes the file and stops.
set_pcap_filter(filter)int674Installs +FILTER= when that plusarg is set. Failure closes the file.
close_pcap()void670, 676, 717, 758, 815Closes the file on a bad DLT, a bad filter, an oversized frame, or at the end.
fetch_next_packet()int710, 752Next stored length. Zero means the file ended. Line 752 is the second frame when BOTH=1.
get_wire_len()int720, 768On-wire length. It can be larger than the stored snaplen.

get_ts_usec()int722, 768Microseconds field. With TS_GAP=1 that value is idle clocks before the frame.

get_bpf_skip()int817Frames the BPF filter dropped before they reached the bridge.

score_ing compares the observer sum on the ingress wire with the fingerprint saved above. A mismatch increments mis.

MAC table

This is the C twin of pkt_l2br. The same plusargs are copied in once, then each accepted frame is predicted, and the 1024 slots are compared after traffic stops.

FunctionReturnsLineRole
l2_set_age(n)void655Copies +AGE= into the C table once reset rises.
l2_set_len(mode)void656Copies +LEN=. Mode 0 is 12 to 2048, mode 1 is 64 to 1518, mode 2 is 64 to 9000.
l2_set_mcast(en)void657Copies +MCAST=. When set, one static group is installed on port B.
l2_reset()void658Clears the C table on that same reset.
l2_predict(port, da, sa, nbytes, vid)int334Called from score_ing for each accepted ingress frame. Returns 0 filter, 1 forward, 2 flood, or 3 drop. A mismatch with a_dec_act or b_dec_act increments mis.
l2_tick()void506One C-table clock per posedge clk while rst_n is high, after the observers score that edge.
l2_slot_valid(i)int801Valid bit of C slot i, compared with u_br.cam_v.
l2_slot_mac(i)longint804MAC in that slot, compared with u_br.cam_mac.
l2_slot_port(i)int805Port in that slot, compared with u_br.cam_prt.
l2_slot_vid(i)int806VID in that slot, compared with u_br.cam_vid. A mismatch on any of the four is added to mis.

The slot walk runs after the ports go idle. It covers all 1024 entries. Stamps are not compared.
